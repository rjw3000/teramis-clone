# teramis-clone

Next.js clone of the public Teramis routes for the termamis.awesome preview.

Copy comes from https://teramis.us/. Forms link to the live Teramis form. /brief is the name note.

The home page is the "Drill-Down Analytics" landing: an Environment → Source → Repository → Location → File explorer (demo data in `lib/explorer.ts`) with `#explore=…` deep links, Esc / back-button navigation, and a light/dark theme toggle.

```
npm install
npm run build
npm start
```
